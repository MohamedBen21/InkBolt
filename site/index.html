How it works

Three things, done well, nothing else.

01

Bolds, never restyles

Only font-weight changes on the first few letters of each word. Your site's font, size, and layout are untouched — always.

02

Works everywhere, live

Search results, infinite-scroll feeds, single-page apps — a background watcher catches new content as it loads, no refresh needed.

03

Tune it, or turn it off

A bold-intensity slider, a global switch, and per-site control — on the sites you want, off everywhere else.

Your e-books, too

Drop in an .epub or .txt file and get back a file in the same format — EPUB stays EPUB, TXT stays TXT (using real bold Unicode characters, not markup). Nothing runs on a server; it all happens in your browser.

Questions

Does this change my site's fonts?

No. Inkbolt only adjusts font-weight on part of each word via an inline style — font-family, size, and line height are never touched.

Is this the "Bionic Reading" app?

No — Inkbolt is an independent implementation of a similar fixation-guided reading idea. "Bionic Reading" is a trademark of a different company; Inkbolt is its own product, unaffiliated.

What e-book formats are supported?

EPUB, TXT, and PDF directly. EPUB and TXT keep their exact original layout and fonts. PDF is rebuilt with the extracted text in a clean standard layout, since PDFs don't have reflowable text the way EPUB does — so the original's exact fonts, columns, and images aren't preserved, only the text itself (now bolded). For MOBI, AZW3, or KFX, convert to EPUB first with Calibre (free), then use the converter.

Does it send my browsing or my files anywhere?

No network calls are made with your page content or your files — everything runs locally in your browser.
